# Operator logos

Shown on the Scanner page's network card for the operator the panel detects (`NetworkCard.vue`), one per short
code of `hutils/network/maxmind.py`. Each file is the operator's logo (or its mark) trimmed and centred on a 192×192
square of its own background colour. The names and logos are trademarks of their companies and are used only to show
which operator was detected. An operator without a file here keeps the generic icon.
